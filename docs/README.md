# docs/ — submission documents and their build pipeline

## Deliverables

`docs/submission/` contains the five Word documents and one ZIP bundle:

1. `01_ORBITAL_GUARD_Project_Report.docx`
2. `02_ORBITAL_GUARD_Technical_Documentation.docx`
3. `03_ORBITAL_GUARD_Dataset_and_Model_Evaluation.docx`
4. `04_ORBITAL_GUARD_Testing_and_Verification_Report.docx`
5. `05_ORBITAL_GUARD_User_Manual_and_Learning_Guide.docx`
6. `ORBITAL_GUARD_Submission_Documents.zip` (the five documents)

Each document contains the shared **Project Milestones** section with exactly five
milestones, numbered figures with captions and explanations, numbered tables,
running headers and "Page X of Y" footers.

## How every figure was produced (no fabricated visuals)

| Asset folder | Contents | Origin |
|---|---|---|
| `assets/screens/` | 16 screenshots | Real captures of the running production build, driven by `tools/shoot.js` (Puppeteer). Each result screen was produced by actually clicking Run / setting the propagation window. |
| `assets/dataset/` | 4 real telescope frames + labels | Extracted from the verified StreaksYoloDataset archive with HTTP range requests (`tools/fetch_sample.py`). CC BY 4.0. |
| `assets/figs/` | 17 diagrams and data plots | Generated by `tools/make_figures.py`. Data plots read `docs/evidence/*.json` and `ml/experiments/*.json`; diagrams are schematic and captioned as such. |
| `assets/photos/` | 1 photograph, 1 illustration | Telescope photograph: Jason D / Pexels. Earth-debris image: generated illustration, explicitly captioned as an illustration (debris cannot be photographed at planetary scale). See `assets/photos/CREDITS.md`. |
| `assets/opt/` | print-optimised copies | `tools/optimize_assets.py` — picks the smaller of PNG/JPEG per image; used when embedding. |
| `evidence/` | JSON evidence | Live API responses, Zenodo record metadata and the MD5 verification record. |

## Rebuild everything

```bash
npm run build && npx next start -p 3000 &      # the app must be running for screenshots
python3 docs/tools/fetch_sample.py --out docs/assets/dataset --split test --count 4
NODE_PATH=/path/to/puppeteer/node_modules node docs/tools/shoot.js
python3 docs/tools/make_figures.py
python3 docs/tools/optimize_assets.py
python3 docs/tools/build_docs.py               # writes the five .docx files + ZIP
```

Python requirements for the document pipeline: `python-docx`, `matplotlib`, `pillow`, `numpy`, `requests`.
Puppeteer is installed outside the project so it never becomes an application dependency.

## Honesty rules enforced in the documents

* Every number is traceable to an evidence file; nothing is estimated or invented.
* Synthetic tracking and benchmark results are labelled **synthetic** in the text and on the figures.
* Streak detection is never described as debris identification.
* No collision probability is claimed anywhere; the reason (no covariance in TLEs) is stated.
* The negative P2 result is preserved and explained.
* The dataset identifier was verified against the publisher's record: size and MD5 match
  (`evidence/dataset_verification.json`).
